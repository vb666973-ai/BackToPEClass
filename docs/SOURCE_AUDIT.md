## Decisions
- Latest request authorizes original complete routines now; all twelve sessions are populated, rather than withheld pending supplied content.
- Draft exercise instructions are not represented as professionally reviewed or ready for commercial release.
- Browser companion is prioritized by the latest request; the same written source generates downloadable PDFs.
- Six original playable schematic cue guides provide useful movement references. They are explicitly not filmed trainer videos, not certified demonstrations, and not rights-approved customer video delivery.
- Local MP4/WebM/VTT playback is a browser-only preview. Selected files are never uploaded, persisted, included in PDF, or represented as approved.
- No passcode, admin gate, fake authentication, fake checkout, pricing, sales, professional credentials, or invented contacts are included.
- Durable CMS, server-side admin authentication, approved release storage, and operational content backups remain separate future backend milestones. Browser storage only records customer progress; it is not a CMS source of truth.
- Two AI hero-image generation attempts failed. No nonexistent image is imported. Original UI artwork and a decorative external gym-court photograph are used instead. The photo hides on failure; layout remains usable.
